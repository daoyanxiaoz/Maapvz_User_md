# 快速开始

💡 TIP

已经购买了 Mirror 酱 服务？试试 高速下载！

  1. 在 release 页面 下载最新版本。

  2. 在模拟器设置里将分辨率调整为 1920×1080 并 锁定屏幕旋转 为横屏。

  3. 调整软件配置，然后点击 开始任务。

ℹ️ INFO

如果遇到问题，请先仔细阅读 常见问题解决方案。
