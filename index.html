# 快速开始

💡 前置条件

如果你没有安装过环境配置，需要去群文件或者 下载 .NET 10.0。

  1. 下载安装脚本：可以在 GitHub Releases 或群文件下载最新日期 maapvz 包，解压并打开。

  2. 先安装 dotnet-runtime，然后双击 MaaPvz.exe 即可看到配置页面。

ℹ️ 主界面说明

所有拥有导航的任务在执行完毕后和执行前都会优先导航一次主界面。有些限时或特殊活动未做导航，需要用户自行配置。

# 主要功能

# 签到

  • 每日签到：自动完成游戏内签到。

# 免广告卡

免广告卡功能，可以自行开关，包含以下三项功能：

  • 免费50钻：自动领取每日免费50钻石（需拥有免广告卡）。
  • 潘妮秘宝：自动完成潘妮秘宝相关操作。
  • 超Z钥匙：自动领取超Z联赛钥匙奖励。

# 植物探险

选择对应的植物（一般选4个即可），自动进行探险，如果你选择了多个选项，探险次数用完或者正在探险的植物会自动跳过，然后去探险多余选择的植物。

# 碎片挑战

植物配置是你需要的最低要求植物。目前不支持雪人危机。支持选择多个植物，优先级：紫卡 > 蓝卡 > 绿卡 > 白卡。

# 潘妮秘宝

进入游戏后直接开启任务即可自动完成。

# 刷胜场/金币

用于快速刷取胜场和金币，支持两种模式，可灵活选择刷取次数。

模式一：埃及1（无需配置）

  • 特点：不需要额外配置，开箱即用。
  • 适用场景：快速刷金币和基础胜场。

模式二：功夫13（需街机神器）

  • 前置条件：需要一个 九级街机神器。
  • 自动装备：可自行选择是否开启“自动装备街机神器”功能。
⚠️ 重要提示

若未装备街机神器，脚本运行会出现 bug，请务必确认神器已装备或开启自动装备功能。

刷取次数

  • 刷十把：运行10局后自动停止。
  • 一直刷：持续运行，直到手动停止。

两种模式均支持上述次数选项，可根据需求自由选择。

# 幸运宝藏

自动领取幸运宝藏。

💡 建议

建议将此任务放置在 刷金币/胜场10把后 运行，可有效利用游戏机制，获得更佳收益。

# 创意庭院

自动在创意庭院中执行刷取任务，支持两种模式，可灵活选择。

模式一：刷游玩币

  • 功能：自动游玩创意庭院关卡，获取游玩币。
  • 特性：当可刷取的代币达到上限时，会自动停止并退出。

模式二：刷点赞

  • 功能：自动创建关卡并点赞，提升关卡热度。
  • 自定义次数：可设置 点赞次数，脚本将循环创建关卡并进行点赞，达到指定次数后停止。
⚠️ 注意事项

使用期间请保证 剪切板不被其他操作干扰（如复制粘贴其他内容），否则可能导致脚本运行异常。

# 旅行原木

进入游戏后直接开启任务即可自动完成。

# 小工具

提供一些辅助功能，可根据需求选择不同的工具使用。

# 无尽测定向序列

使用步骤：

  1. 在游戏内进入 植物 → 编队，将想要进化的植物放入 编队 6（必须编满）。
  2. 确认摆放无误后点击“开始任务”。
  3. 若存在其他无尽训练进度，系统会强制停止，需手动清除干扰进度。

# 日志清理

清理多余日志，防止日志文件过多导致存储溢出。

# 双人对决

默认为自选模式。如果不熟悉配置，建议先开启“帮选模式”观察，再参照配置植物。

  • 近战植物配置：热辣海藻类植物会往后摆一格。
  • 远程植物配置：热辣海藻类植物会往前摆一格（避免仙人掌缩头）。

# 时空秘境

地宫1无尽

  • 自动配置：主界面直接开启（需在商店买满初始阳光）。
  • 手动配置：先手打几关，保证有一列双发，然后在选卡界面开启手动配置，期望刷取100+关。

地宫2无尽

  • 自动代理：主界面直接开启。
  • 手动代理：进入地宫2，手动推几关，摆放双发至指定位置后，在下一关开启脚本。

建议手动帮忙领取阳光（有蓓蕾3000左右，电藤五千左右），或使用月卡自动收集。阳光蓓蕾期望100+关，电藤200+关。

# 进阶设置

  • 单独运行：右键单个任务的齿轮，选择“单独运行”来启动该任务。
  • 定时执行：点击设置 → 定时执行，可设置全自动植物探险等定时任务。
  • 导出日志：出现bug时，导出日志用于反馈。
  • 碎片挑战多植物选择：通过添加任务 → 碎片挑战，然后长按拖动排序，在设置里更改不同植物即可（优先级自动按品质排列）。
