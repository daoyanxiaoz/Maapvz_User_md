# 原大桑葚无尽挂机脚本

专为无尽模式挂机设计，自动完成抛花、Boss关喂豆、补种植物等关键操作，解放双手。

核心功能

功能说明
普通关抛花（可选）每小关自动抛 2 朵 能量花，位置固定：9-1、9-2
Boss关喂豆（可选）Boss关 一直喂豆直到结算，位置固定：(5-3)
选卡逻辑优先选择 桑葚、毒藤、大哥，其余全选橙色植物
卡槽容错若没有“大哥”，自动替换为 泡泡姬珊瑚

使用前准备

1. 卡槽配置

脚本依赖 固定卡槽顺序，请确保植物位于对应卡槽（后两个植物随意）。

2. 抛花前提

  • 普通关抛花位置：(9-1)（右上角第一格）、(9-2)（右上角第二格）
  • 请确保这两个格子 空余或可丢弃能量花，否则抛花可能失败。

3. Boss关喂豆前提

  • 喂豆位置固定：(5-3)
  • 5-3 种的植物为卡槽第7个，可自行替换（建议放输出或控制类植物）
  • 脚本会一直喂豆直到Boss关结算。

4. 选卡规则（自动执行）

优先级植物选择备注
1桑葚、毒藤、大哥优先选这三个，缺一不可
2其他全选橙色植物尽量选橙色品质
容错无大哥 → 替换为泡泡姬珊瑚脚本自动处理

使用说明

⚠️ 使用前先选择阵容

卡槽配置

# 无尽挂机框架（通用）

轻量、灵活的挂机辅助框架，默认执行点波和天空划飞弹操作，您可自由配置专属阵型。

# 喂豆配置

  • 小关喂豆：是否在普通关喂豆，可开启“是否开局喂豆球果”功能。
  • 喂豆位置：循环喂能量豆的位置（坐标输入）。
  • 喂豆间隔：每次喂豆的间隔时间（4秒~100秒可选）。
  • Boss关喂豆：位置和间隔可独立设置。

# 抛花配置

  • 是否抛花：全局开关，关闭后不执行任何抛花操作。
  • 小关抛花：可分别设置1花和2花的位置坐标。
  • Boss关抛花：可分别设置4个抛花位置（boss关_1花~4花）。
  • 识别能量花卡槽位置：开启后能量花可放在任意卡槽位置（默认固定在卡槽1）。

# 补植物配置

  • 是否需要补植物：开启后，在每关结算后自动补种上一关损失的植物。
  • 卡槽2~5补植物：每个卡槽可设置5个补种位置（坐标输入）。
  • 铲除植物：在补植物后，可对指定位置执行铲除操作（最多5个位置）。

# 魔甘收尾

⚠️ 牢玩家专属

开启后大部分其他功能会失效，请慎重开启。

  • 魔甘收尾：魔音甜菜位于卡槽4，飓风甘兰位于卡槽5，甜薯位于卡槽6。
  • 种植位置：魔音甜菜种在9-3，飓风甘兰种在7-2和7-4，甜薯种在8-2和8-4。
  • 使用三叶草：三叶草位于卡槽7，种植在9-5。
  • 魔甘前使用能量豆：可在魔甘收尾前对指定位置使用能量豆。

# 加速配置

  • 小关是否加速：进入普通关后是否开启加速键。
  • Boss关是否加速：进入Boss关后是否开启加速键。

# 自定义布阵

💡 建议手动布阵

建议手动布阵，最好不要开启此功能，以免出现不可预知的问题。

  • 自定义布阵：开启后可使用自定义阵型。
  • 卡1~卡8种植：每个卡槽可设置最多10个种植位置。
  • 种守卫菇：可设置5个守卫菇种植位置。
  • 铲子功能：种守卫菇前后可使用铲子清除指定位置。
  • 布阵后喂豆：布阵结束后可对指定位置喂豆。
  • 回到后期：可设置第几关布好阵，开始使用预设配置。

# 🔄 无尽全自动循环

打一遍后自动花钻石刷新重新打，实现真正的全自动挂机。

  • 开启：打完一局后自动使用钻石刷新，重新开始。
  • 关闭：打完一局后停止，不自动刷新。
ℹ️ 说明

该功能需要消耗钻石，请确保钻石充足。全自动循环适用于所有预设模式和通用框架。
