# 原大桑葚无尽挂机脚本

专为无尽模式挂机设计，自动完成抛花、Boss关喂豆、补种植物等关键操作。

  • 普通关抛花：每小关抛 2 朵能量花，位置 9-1、9-2。
  • Boss关喂豆：一直喂豆直到结算，位置 (5-3)。
  • 选卡逻辑：优先桑葚、毒藤、大哥，其余全选橙色植物。

# ⚙️ 通用框架

通用框架是 MaaPvz 无尽模式的核心辅助系统，分为前期布阵（custom）和后期布阵（fw）两大模块，分别对应布阵阶段和挂机阶段的配置。下面按模块逐一说明。

# 🌱 前期布阵（custom）

前期布阵用于在无尽前期（通常为1~4关）自动布置阵型，包含卡槽种植、守卫菇、铲子、喂豆等操作。所有配置均对应 JSON 中 option 下以 frame_wj_custom_ 开头的选项。

ℹ️ 触发条件

前期布阵在 自定义布阵 开关开启时生效，通常配合 frame_wj_custom_回到后期 设置转换关卡。

# 卡槽种植（卡1~8）

为每个卡槽（1~8）设置种植位置，每个卡槽最多可配置 10 个 种植点位。

配置项卡1种植 ~ 卡8种植
类型开关（嵌套坐标输入）
最大次数每卡槽 10 次
坐标格式列-行（如 5-3）

使用建议：按卡槽顺序依次布置，建议先布核心输出植物，再布辅助植物。坐标从 1-1（左上角）到 9-5（右下角）。

# 守卫菇

在指定位置种植守卫菇，给周围植物二次开大，最多可设置 5 个 种植位置。

配置项frame_wj_custom_是否种守卫菇
子项frame_wj_custom_种守卫菇位置1 ~ 位置5
最大次数5 次

守卫菇种植后会自动喂豆并铲除（取决于铲子配置），实现“种→喂→铲”的循环操作，让周围植物获得二次开大的机会。

# 铲子（前/后）

分为 守卫菇前铲子 和 守卫菇后铲子 两组，每组最多 5 个铲除位置。

前铲子开关frame_wj_custom_是否使用铲子1
前铲子位置frame_wj_custom_使用铲子1 ~ 铲子5
后铲子开关frame_wj_custom_是否使用铲子2
后铲子位置frame_wj_custom_使用铲子6 ~ 铲子10
  • 前铲子：在种守卫菇之前铲除指定位置的植物（用于清除过渡植物）。
  • 后铲子：在种守卫菇之后铲除指定位置的植物（用于清除守卫菇）。

# 喂豆（小关 / Boss）

前期布阵中的喂豆配置，与后期布阵的喂豆相互独立，仅在前期阶段生效。

小关喂豆开关frame_wj_custom_布完阵是否喂豆
小关喂豆位置frame_wj_custom_喂豆位置 + 坐标
Boss喂豆开关frame_wj_custom_boss关是否喂豆
Boss喂豆位置frame_wj_boss_custom_喂豆位置 + 坐标
Boss喂豆间隔frame_wj_boss_custom_喂豆间隔（1~10 秒）

# 🌿 后期布阵（fw）

后期布阵用于阵型成型后的挂机阶段，包含补植物、铲除、喂豆、抛花、魔甘收尾等核心功能。对应 JSON 中 option 下以 fw_ 开头的选项及部分通用开关。

# 补植物

每关结算后自动补种上一关损失的植物，保障阵型完整性。

开关是否需要补植物
补种卡槽卡槽2_补植物 ~ 卡槽8_补植物
每卡槽次数最多 8 个位置

补植物只针对卡槽2~8，因为卡槽1通常为能量花等辅助植物，不需要补种。

# 铲除

在补植物完成后，对指定位置执行铲除操作，用于调整阵型或清理多余植物。

开关铲除植物
位置铲除植物1 ~ 铲除植物5
最大次数5 次

# 喂豆（小关 / Boss）

后期挂机阶段的喂豆配置，与前期布阵的喂豆独立。

小关喂豆开关小关是否喂豆
小关喂豆位置小关喂豆位置 + 坐标
小关喂豆间隔小关喂豆间隔（4~100 秒）
Boss喂豆开关fw_boss关是否需要喂豆
Boss喂豆位置fw_boss关喂豆位置 + 坐标
Boss喂豆间隔fw_boss关喂豆间隔（默认 4 秒）

# 喂豆球果

在关卡开局时立即对指定位置使用能量豆，用于快速启动输出。

开关是否开局喂豆球果（依赖 小关是否喂豆）
位置喂豆球果 + 坐标
💡 提示

喂豆球果仅在 小关是否喂豆 开启时生效，且需要在小关喂豆位置已经布置后使用。

# 抛花（小关 / Boss）

在指定位置抛种能量花，收集能量豆供喂豆使用。需先开启 是否抛花 总开关。

总开关是否抛花
小关抛花开关小关是否抛花
小关抛花位置1花位置、2花位置（各 1 个）
Boss抛花开关boss关是否抛花
Boss抛花位置boss关_1花位置 ~ _4花位置

Boss关可抛 4 朵花，小关可抛 2 朵，充分利用能量花产出。

# 魔甘收尾

🚨 牢玩家专属

开启后大部分其他功能会失效，请慎重开启。

使用魔音甜菜 + 飓风甘蓝（+甜薯）在关卡末尾将僵尸吹飞，实现快速清场。

基础配置

开关是否魔甘收尾(牢玩家专属)
等待时间多少秒后种魔甘（默认 15 秒）
使用三叶草使用三叶草（卡槽7，种在 9-5）

默认站位（未开启识别时）

  • 魔音甜菜：卡槽4 → 种在 9-3
  • 飓风甘蓝：卡槽5 → 种在 7-2、7-4
  • 甜薯：卡槽6 → 种在 8-2、8-4
  • 三叶草：卡槽7 → 种在 9-5（若开启）

高级选项

  • 识别魔甘卡槽位置：允许魔音/甘蓝/甜薯放在任意卡槽（需开启识别）。
  • 魔甘前使用能量豆：可指定喂豆位置增强魔甘效果。
  • 魔甘失败后是否重开：若失败自动重开（有气流水仙花可关闭）。
  • 甜薯1/2种植位置、飓风甘蓝1/2种植位置：自定义种植坐标。

# 🔄 全自动循环

打完一局后自动花钻石刷新重新打，实现真正的全自动挂机。

开关无尽全自动循环
开启打完一局后自动使用钻石刷新重新开始
关闭打完一局后停止，不自动刷新
ℹ️ 说明

该功能需要消耗钻石，请确保钻石充足。适用于所有预设模式和通用框架。
