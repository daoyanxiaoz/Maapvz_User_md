# 🏰 无尽作业集教程

📖 预计阅读时间: 20 分钟
ℹ️ 什么是作业集模式？

作业集是最新版本的无尽挑战模式：支持 149 关卡切换、全自动挂机，并且支持 导入导出作业集。在 MaaPvz 中更新到最新测试版即可体验。

# 序章

点击「编辑作业集」并运行一次，即可打开 html 作业集工具。

▲ 点击「编辑作业集」并运行一次

后续切换为「运行本地作业集」，且每次运行之前请点击「保存作业集」——会使用你目前选择且保存的作业集进行过关。

# 2. 导入作业集

这个板块教你如何使用别人分享的作业集。

⚠️ 必须保存一次才能用

导入作业集之后，必须先保存一次作业集才可以使用，否则配置不会生效。

▲ 导入作业集之后，保存一次才可以使用

保存作业集后，在 MaaPvz 中将任务选项切换为「使用本地作业集」，该选项会使用网页端选择并最新保存的作业集。

# 3. 基础操作

3.1 落子

把植物槽拖到棋盘格子上，即为一次落子。

  • 同一个格子可以重复放置（最多 9 个），超出后显示 +N 角标。
▲ 落子演示：把植物槽拖到棋盘格子上

3.2 快捷键

  • WASD：移动光标 / 选格。
  • 右键 / F：切换落子动作。
▲ WASD 移动光标 / 选格
▲ 右键 / F 切换落子动作

3 种落子动作各自的用途：

  • 喂豆：给格子喂能量豆。
  • 铲子：铲掉格子上的植物。
  • 点击格子：只点不种。

3.3 三条链与顺序

拖动即可调整各步骤的执行顺序：

▲ 单次链修改顺序：这个大哥将会在喂豆结束后种植

三条链的语义：

  • 单次链：进局内执行一次（开局布阵）。
  • 循环链：反复执行（补种 / 喂豆）。
  • 收尾链：有两种触发状态——
    • ① 识别僵尸头像走到最后一波后执行；
    • ② 循环链执行一定次数后执行。

收尾链执行后的超时后动作，可选三种：

  • 重开
  • 执行子动作（单次 / 循环 / 收尾）
  • 识别结算

Boss 关：

  • 棋盘顶部可切换 普通 / Boss 两套棋盘与链。
  • Boss 阵容可沿用普通关，也可以切换编队。
  • Boss 关没有收尾链。

# 5. 通用动作与神器

5.1 通用动作按钮组

通用动作按钮组包含：点波 / 捡豆 / 加速。

▲ 通用动作和神器的 UI 演示

「更多」里的三个动作：

  • 切换形态：选槽位 N 次。
  • 自定义动作：从坐标表挑键名，支持点击 / 滑动 / 长按 / 多指。
  • 滑飞弹 🚀：默认 10ms × 20 原子连击，一般用于天空无尽。

5.2 神器板块

操作流程：选神器 → 根据自己神器的类型选择对应的操作 → 插入「使用神器」（见上方同一张演示图）。

5.3 等待节点 ⏱

在某一步后面插入一个等待节点，并设置等待时长：

▲ 等待节点的插入与时长设置

5.4 ⚙ 步骤设置（调配参数）

  • 连击次数 ×N / 连击间隔 ms / 连击参与识别开关。
  • 连击说明：所有动作自带 0.1 秒的间隔，使用连击 + 连击不参与识别时，才会使单个动作执行没有间隔。
  • 滑动时长：0 = 瞬滑；滑飞弹有独立时长（默认 10ms）。
  • 相邻多步可标成无间隔组 「」：连发不插间隔。

# 6. 阵容管理

6.1 局外选卡

选择卡组时，局内和局外卡组都可以右键收藏。

▲ 局外选卡演示

6.2 自动选卡慢？

如果自动选卡很慢，可以修改为 一键选取 和 复用已有配置：

  • 一键选取：收藏好准备上阵的植物再开启。
  • 复用当前配置：如果你已经选了 80 张卡，那么就会直接点确定。

# 7. 保存与运行

⚠️ 保存 = 编译

改完必须保存才生效，没有保存的修改不会被应用。

  • 起始关卡：在作业集设置里配置。
  • 运行日志：运行中在右下角查看，或在调试目录中查阅。
