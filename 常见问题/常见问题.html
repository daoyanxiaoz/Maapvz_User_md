# 📋 日志导出

# 导出日志步骤

当遇到脚本运行异常或 Bug 时，导出日志是反馈问题的重要途径。请按以下步骤操作：

第一步：打开日志导出界面

▲ 点击“导出日志”按钮

第二步：选择保存位置并导出

▲ 选择保存路径，点击“保存”即可导出日志文件

💡 提示

导出的日志文件（一般为 .zip格式）包含程序运行的详细记录，请将其提供给开发人员以便快速定位问题。

# 启用截图模式

截图模式 是为了更精细地获取日志信息而设计的辅助功能。在遇到难以复现的 Bug 时，开启截图模式可以捕获更多的运行细节。

▲ 在设置中开启“截图模式”

使用场景

  • 疑难 Bug 定位：当常规日志不足以定位问题时，截图模式可提供额外的视觉信息。
  • 界面识别异常：当脚本提示识别失败时，截图模式可以帮助开发人员了解当时的屏幕状态。
  • 功能测试验证：开发人员可通过截图模式验证特定功能的执行情况。
⚠️ 注意事项
  • 截图模式会占用更多存储空间，建议仅在排查问题时临时开启。
  • 开启截图模式后，程序运行速度可能略有下降，属于正常现象。
  • 导出日志时，截图会一并打包，请注意隐私信息（如账号等）。

# ⚔️ 双人对决

# 悬浮窗遮挡识别区域

⚠️ 问题描述

在运行 双人对决 任务时，模拟器的悬浮窗（如操作录制悬浮球、游戏加速器悬浮窗等）可能会遮挡游戏界面的关键识别区域，导致脚本无法正确识别当前状态，从而造成任务执行失败或卡死。

▲ 如图所示，悬浮窗遮挡了识别区域

✅ 解决方案

  1. 找到悬浮窗：检查模拟器屏幕上是否有任何悬浮图标（如操作录制、加速器、游戏工具箱等）。
  2. 拖动悬浮窗：长按悬浮窗，将其拖拽到屏幕的 边缘或角落位置，确保不遮挡游戏界面的核心区域。
  3. 临时关闭悬浮窗：如果拖拽后仍然影响识别，可以尝试 暂时关闭悬浮窗（通常在悬浮窗上右键或双击可关闭）。
  4. 重新运行任务：调整完毕后，重新启动双人对决任务，观察是否恢复正常。
💡 建议

为了获得最佳体验，建议在运行 双人对决 及其他自动化任务时，提前将所有悬浮窗移动到屏幕边缘，或在使用脚本期间 暂时关闭不必要的悬浮工具。

# 不要打开后台保活

⚠️ 问题描述

在运行 双人对决 任务时，如果开启了模拟器的 后台保活 功能，可能会导致游戏进程在后台被系统强制重启，从而中断自动化任务，造成脚本异常。

▲ 后台保活设置界面（示例）

✅ 解决方案

  1. 关闭后台保活：进入模拟器的设置或游戏加速器设置，找到 后台保活类似选项，将其 关闭。
  2. 重启模拟器：关闭设置后，建议重启模拟器以确保设置生效。
  3. 重新运行任务：重启后，再次启动双人对决任务，观察是否恢复正常。
💡 建议

为了确保自动化任务稳定运行，建议在运行 双人对决 及其他长时间任务时，关闭所有可能干扰游戏进程的优化功能，包括后台保活、省电模式等。
